# slow

slow(n, p) or `p |> slow(n)` — stretches ×n. slow(2) plays once every 2 cycles.

Stretches the pattern over n cycles: `slow(2)` plays it once every two cycles. A four-step pattern slowed by 4 plays one step per cycle — the way to write a chord progression that changes every bar.

See also: fast, cycle
