# randcat

Each cycle, plays one of the patterns drawn at random (deterministic).

Each cycle, plays one of the patterns at random, deterministically: `randcat(["bd*4", "bd . sn", "~ cp"])` is a drum machine that never quite repeats.

See also: cat, wrandcat, sometimes
