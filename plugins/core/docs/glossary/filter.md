# filter

The low-pass keeps the lows, the high-pass the highs, the band-pass a window, the band-reject everything but a window. `cutoff` sets where it acts, `q` or `resonance` how sharply. Most synth sounds are an oscillator into a filter into an envelope.

See also: low-pass filter, high-pass filter, band-pass filter, cutoff, resonance
