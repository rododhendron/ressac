# harmonic

A sawtooth has every harmonic (1f, 2f, 3f…), a square only the odd ones, a sine just the fundamental. Filters remove harmonics, distortion adds them. Partials that are not whole multiples make bells and metal sounds.

See also: harmonic series, fundamental, timbre, distortion
