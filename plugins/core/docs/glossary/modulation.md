# modulation

Modulation is what turns a static sound into a living one. Frequency modulation (FM) makes bells and metal, amplitude modulation makes tremolo and ring-mod, filter modulation makes wobble. The MODULATION pane lets you move a drone's arguments by hand.

See also: LFO, FM, envelope, drone
