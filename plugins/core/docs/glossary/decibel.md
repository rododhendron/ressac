# decibel

Ears hear ratios, not differences, so levels are counted in decibels. 0 dBFS is the loudest a digital signal can be; -12 dB is a quarter of that. The mixer meters and the compressor `threshold` speak dB.

See also: amplitude, compressor, threshold
