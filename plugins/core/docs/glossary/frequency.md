# frequency

A 440 Hz sine is the A above middle C; doubling the frequency raises the pitch by one octave. `freq` sets it directly on a synth, `n` and `note` set it in semitones, `cutoff` and `lpf` are frequencies too — the point where a filter starts cutting.

See also: pitch, octave, semitone, cutoff
