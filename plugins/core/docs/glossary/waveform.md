# waveform

The shape decides which harmonics are present. `sin_osc` is pure, `saw` is bright and full, `pulse` is hollow, `tri` is soft. The wave view in DESIGN shows the actual waveform of a synth.

See also: sine, sawtooth, square wave, oscillator
