# spiral

Shows this slot's cycle wound into a spiral under its line; the pattern is unchanged.

One turn is one cycle; three turns are drawn, the current one outside. The hand shows where the cycle is, the sounding notes are lit. Drawn in pixels under the slot's block (kitty graphics protocol).
