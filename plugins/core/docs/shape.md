# shape

Waveshaper drive (0-1). Subtle saturation at 0.1, heavy distortion at 0.5+.

SuperDirt's waveshaper, 0 to 1: 0.1 adds grit, 0.3 is a warm overdrive, 0.6 and above is heavy distortion that also raises the level — bring `gain` down with it.

See also: distortion, saturation, crush
