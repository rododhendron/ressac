# begin

Start position in the sample (0-1).

Where the sample starts playing, 0 to 1 of its length. `begin` is a Julia keyword, so the function is written `begin_`: `begin_(0.5)` skips the first half; with `end_` it isolates a slice by hand.

See also: begin_, end_, slice, sample
