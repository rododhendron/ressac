# rev

rev(p) — reverses the events within each cycle.

Plays the events of each cycle backwards. Combined with `every` it is a fill, with `jux` a stereo widener (`jux(rev)`: the straight pattern on the left, the reversed one on the right).

See also: every, jux, palindrome
