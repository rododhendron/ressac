# velocity

Note velocity (0-1). Often mapped to amplitude or cutoff.

How hard the note is hit, 0 to 1. Synths map it to amplitude or brightness; it is the natural control for human-like accents (`velocity("0.9 0.5 0.7 0.5")`).

See also: gain, amplitude
