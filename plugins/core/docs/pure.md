# pure

pure(v) — pattern that emits v once per cycle. The atom everything is built on.

A pattern that emits one value once per cycle: `pure(:bd)` is a kick every cycle. It is what `:bd` and `"bd"` become, and the atom the combinators build on.

See also: pattern, cycle, event
