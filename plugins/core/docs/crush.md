# crush

Bit-crush depth (1 = destroyed, 16 = clean). 6-8 = lo-fi.

Bit depth reduction: 16 is clean, 8 is lo-fi, 4 is noise. Pairs with `coarse` (sample-rate reduction) for the full early-sampler sound.

See also: bit crushing, coarse, aliasing
